# Kozu UI fonts

Use Inter for body, controls and financial values in Accounts, Tasks and Activity. Prefer 17 logical units for prose and use tabular figures for aligned amounts. Use Helvetica Neue for compact display and voice headings, with Inter or system sans as fallback. Use Menlo for telemetry, with a platform monospace fallback. Native system chrome uses the platform face.

## Inter

The web prototype loads `InterVariable.woff2` with weights 100–900. Install the Inter desktop face to edit the kit in FigCraft. After substituting a font, check wrapping and numeric alignment. The PDF and PNG exports preserve the reviewed layout.
