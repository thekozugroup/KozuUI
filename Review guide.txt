Kozu UI 1.0 review guide

Open Kozu Universal UI Kit.figcraft in FigCraft to inspect and edit the layers. Open Kozu Universal UI Kit.pdf to review all 31 boards in order. Previews contains a PNG of each board.

Start on page 01 and select a product. Use FigCraft presentation mode to follow the prototype actions. In the browser, open web/index.html from disk and choose a product in the top navigation.

Paylane
Open Account home, then Analytics. Compare the white sheet, selected date, two-tone balance and Pay and Request controls. Review Weekly update and Home-screen widgets alongside the phone views.

Synq
Start on Listening. Stop the sample, review and queue the task, then inspect the expanded agent. Compare the light passing through the agent panel with the darker transcript area. Page 06 shows the animated and steady listening states side by side with numeric progress.

Nightshift
Open Command, Investigating and Resolved incident in sequence. Follow the same incident through its timestamps, histogram, closure and report command.

Components and platforms
Use page 07 for the masters and page 08 for TV, watch, widget and wide desktop examples. Inspect icon source shapes on page 09.

When leaving feedback, include the page, artboard and component or action. For layout or interaction issues, note the viewport or platform and the state that exposed the problem. The web prototype runs sample interactions locally. Native watch, TV and widget behavior needs testing on the target host.
